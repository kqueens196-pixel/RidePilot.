# RidePilot

ONE APP. EVERY RIDE. MORE CONTROL.

RidePilot is a multi-platform rider assistant architecture for authorized ride and delivery integrations.

## Launch pricing
- First 90 days: ₹99/month
- First eligible ride/order free for new users during the first 90 days
- Day 91 onward: ₹150/month renewal
- Optional One-Day Pass: ₹10, with explicit expiry shown before purchase

## Important
Automatic acceptance is implemented only through official provider APIs/partner integrations and approved scopes. RidePilot does not collect third-party passwords/OTPs or bypass provider security.

## Modules
- Android rider app
- Backend API
- Provider connector framework
- Matching/auto-accept engine
- Admin portal blueprint
- Subscription and entitlement rules
